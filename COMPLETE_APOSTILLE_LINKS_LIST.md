## 🎯 **ИСПОЛЬЗОВАНИЕ**

### 🚀 **Для автоматической загрузки:**

```python
import requests

def download_apostille(code, security_code):
    url = f"https://apostila.gov.md/apostila/site/downloadApostila/apostileCode/{code}/securityCode/{security_code}"
    response = requests.get(url, verify=False)

    if response.status_code == 200:
        filename = f"apostille_{code}.pdf"
        with open(filename, 'wb') as f:
            f.write(response.content)
        return True
    return False
```

### 📊 **Для использования в архиве:**

1. **Скопируйте ссылки** из текстового файла
2. **Импортируйте CSV** в вашу систему
3. **Откройте HTML** для просмотра в браузере
4. **Используйте JSON** для программной обработки
